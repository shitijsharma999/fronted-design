# Platform 2 Books

A self-contained responsive website for the fictional closing railway-station bookstall "Platform 2 Books".

## Run

No build step is required.

Option 1:
- Double-click `index.html`.

Option 2:
- In this folder run `python -m http.server 8000`
- Open http://localhost:8000

## Features

- Mobile-first responsive layout
- Accessible semantic structure
- Skip link and visible focus states
- Keyboard-accessible book shelf
- Interactive book archive with modal stories
- Last-week schedule
- Functional local campaign form (counter updates in the browser)
- Reduced-motion support
- No image assets required; visual treatment is CSS/SVG
- Under the challenge's ~1.5 MB target when served locally (excluding remote Google Font requests)

## Note

The fictional dates and characters are part of the competition concept.
